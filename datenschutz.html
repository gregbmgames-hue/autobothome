Datenschutzerklärung

Stand: 3. Oktober 2026

Worum es geht

AutobotHome ist eine private Hausautomation, die ausschließlich vom Betreiber für den eigenen Haushalt genutzt wird. Es gibt keine anderen Nutzer und keine öffentliche Anmeldung.

Welche Daten verarbeitet werden

Über die Google Smart Device Management API werden nur Daten der eigenen Nest-Türklingel abgerufen:

  • Ereignisse (Klingeln, Person erkannt, Bewegung) mit Zeitpunkt,
  • kurze Vorschau-Clips zu diesen Ereignissen sowie daraus erzeugte Standbilder,
  • die Geräteliste des eigenen Kontos, um die Türklingel zu erkennen.

Wo die Daten liegen

Alle Daten werden ausschließlich auf dem eigenen Server im Heimnetz gespeichert. Clips und Standbilder werden nach einer einstellbaren Frist (Standard: 14 Tage) automatisch gelöscht. Die Zugangsdaten zur Google-Schnittstelle liegen nur auf diesem Server.

Weitergabe

Daten werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung genutzt. Eine Ausnahme ist die vom Betreiber selbst eingerichtete Benachrichtigung auf das eigene Smartphone (Pushover), die ein Standbild enthalten kann.

Nutzung von Google-Daten

Die Nutzung von Daten, die über Google-APIs empfangen werden, hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit in den Einstellungen des Google-Kontos unter „Drittanbieter-Apps und -Dienste“ oder in der Google-Home-App widerrufen werden.
