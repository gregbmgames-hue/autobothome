AutobotHome

AutobotHome ist eine private Hausautomation für einen einzelnen Haushalt. Sie läuft auf einem eigenen Server im Heimnetz und ist nicht öffentlich nutzbar.

Google-Anbindung

Die Anwendung nutzt die Google Smart Device Management API ausschließlich, um Ereignisse der eigenen Nest-Türklingel (Klingeln, Person erkannt, Bewegung) samt Vorschau-Clip abzurufen und damit Abläufe im eigenen Haus zu steuern, etwa eine Ansage auf eigenen Lautsprechern.

Es gibt keine weiteren Nutzer, keine Registrierung und keine Weitergabe von Daten an Dritte.
